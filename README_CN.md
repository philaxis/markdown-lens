# Markdown Lens

[English](./README.md) | [한국어](./README_KO.md) | [简体中文](./README_CN.md)

Markdown 的语法保持可见时，编辑最直接也最可控。Markdown Lens 将**源码模式**保留为主要工作区，只在光标附近显示一个小型渲染视图，无需切换模式，也不会隐藏源码。

- 渲染整篇笔记，保留链接、公式、图片、代码块、标注框和嵌入内容的上下文。
- 在渲染视图中跟随当前源码行或选区。
- 同样支持 Canvas 文本节点，并补全与普通笔记一致的图片粘贴体验。

## 使用

启用插件，将笔记切换到**源码模式**，然后把光标放入正文。可在插件设置中调整镜头和图片高度。

在进入社区插件目录之前，可通过 BRAT 添加 `https://github.com/philaxis/markdown-lens` 进行安装。

仅支持桌面端。不需要账户，不访问网络，不含广告或遥测。源码不公开；可依照[商业许可证](./LICENSE)用于个人及组织内部业务。
