# Markdown Lens

[English](./README.md) | [한국어](./README_KO.md) | [简体中文](./README_CN.md)

마크다운은 문법이 보일 때 가장 정확하게 다룰 수 있습니다. Markdown Lens는 **소스 모드**를 주 작업 공간으로 유지하면서, 모드를 바꾸거나 문법을 숨기지 않고 커서 주변의 렌더링 결과만 작게 보여줍니다.

- 링크, 수식, 이미지, 코드 블록, 콜아웃, 임베드의 문맥을 유지하도록 노트 전체를 렌더링합니다.
- 현재 소스 행이나 선택 영역을 렌더링 결과에서 따라갑니다.
- Canvas 텍스트 노드에서도 동작하며 일반 노트 방식의 이미지 붙여넣기를 보완합니다.

## 사용법

플러그인을 활성화하고 노트를 **소스 모드**로 전환한 뒤 본문에 커서를 놓으세요. 설정에서 렌즈와 이미지 높이를 조절할 수 있습니다.

커뮤니티 디렉터리 등록 전에는 BRAT에 `https://github.com/philaxis/markdown-lens`를 추가해 설치할 수 있습니다.

데스크톱 전용입니다. 계정, 광고, 텔레메트리를 사용하지 않으며 노트 내용을 전송하지 않습니다. 비공개 소스이며, [상용 라이선스](./LICENSE)에 따라 개인 및 조직 내부 업무에 사용할 수 있습니다.
